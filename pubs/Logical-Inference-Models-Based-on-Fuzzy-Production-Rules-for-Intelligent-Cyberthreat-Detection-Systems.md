# Logical Inference Models Based on Fuzzy Production Rules for Intelligent Cyberthreat Detection Systems

Yuliia Kostiuk <a href="https://orcid.org/0000-0001-5423-0985" target="_blank"><img src="/icons/orcid.svg" width="16" height="16"></a>,

## Abstract

The article proposes an approach to building logical inference models in intelligent cyber threat detection systems based on fuzzy production rules. The main idea is to combine a classic rule-based mechanism (a system based on production rules) with Explainable Artificial Intelligence (XAI) methods, in particular SHapley Additive exPlanations (SHAP) and Local Interpretable Model-agnostic Explanations (LIME), to ensure transparency in decision-making. The developed model implements a fuzzy interpretation of knowledge about attack signs, allowing inference even in cases of incomplete or uncertain input data. The paper presents the structure of the production knowledge base, the defuzzification mechanism, and an example of applying the model to detect a phishing attack with a step-by-step logic for processing input information. A hybrid architecture is proposed that allows the combination of rule-based inference with Machine Learning (ML) methods, ensuring adaptability and increased accuracy. The modeling results demonstrate the effectiveness of this approach for cybersecurity tasks in dynamic environments. The proposed model can be integrated into existing information security systems, such as Security Information and Event Management (SIEM) solutions, Intrusion Detection Systems (IDSs), or cyber incident analysis platforms, to inform explainable decisions regarding the threat level. Modeling results on CICIDS-2017 and UNSW-NB15 showed an accuracy of over 95%, with support for interpretability of decisions through SHAP and LIME modules.
